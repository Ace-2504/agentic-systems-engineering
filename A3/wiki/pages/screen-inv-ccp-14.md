INV-CCP-14 is the Ledgerline cycle count plan entry screen used under [[sop-inv-003|SOP-INV-003 Stock Count (cycle and annual)]][^r1]. As of 26 October 2026, it configures standard counting schedules across inventory item classifications[^r1].

Code: INV-CCP-14
Screen Name: Cycle Count Plan Entry
System: Ledgerline
Procedure: SOP-INV-003

## What it is for
Cycle count plan INV-CCP-14 specifies counting Class A items monthly, Class B items quarterly, and Class C items twice a year[^r1].
