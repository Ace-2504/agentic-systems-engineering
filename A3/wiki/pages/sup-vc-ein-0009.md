VC-EIN-0009 is the legacy supplier account for [[sup-vc-ein-0042|Voltway Cells]] in Ledgerline [^r1]. It is permanently blocked under [[pol-sup-003|POL-SUP-003]] and must not be used for purchasing [^r1]. Staff must instead direct transactions to the active supplier record [^r1].

## Record
In Ledgerline, VC-EIN-0009 is maintained with the explicit name marker '(old code, do not use)' [^r1]. Its status is set to blocked [^r1].

## Certificates
None recorded under this legacy code [^r1].

## Rate contracts
None recorded under this legacy code [^r1].

## Notes
The account is retained solely as a blocked legacy reference [^r1].
