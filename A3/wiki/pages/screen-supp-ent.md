Screen SUPP-ENT is a legacy Ledgerline interface documented in superseded procurement procedures. Under prior processes, it served as the entry screen for setting up new vendor records. It is no longer referenced as an active screen in current onboarding workflows.

Screen code: SUPP-ENT
Purpose: Vendor account creation (superseded)

## What it is for
In superseded [[sop-pur-001|SOP-PUR-001]] v2.0, screen SUPP-ENT was used to create new vendor accounts[^r1].
