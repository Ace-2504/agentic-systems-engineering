Voltway Cells in Eindhoven is an active supplier entity designated under code VC-EIN-0042 [^r1]. It replaces the previous supplier code [[sup-vc-ein-0009|VC-EIN-0009]], which was blocked and marked '(old code, do not use)' upon assignment of the new code [^r1][^r3]. Name variations appearing on quotations and e-mails must be recognized and treated under this active record [^r1][^r2].

## Record
Voltway Cells (Eindhoven) is the active supplier record replacing previous code [[sup-vc-ein-0009|VC-EIN-0009]] [^r1]. When this new supplier code was assigned, the prior record [[sup-vc-ein-0009|VC-EIN-0009]] was blocked and marked '(old code, do not use)' [^r3].

## Notes
Name variants such as 'Voltway Cells B.V.' or 'VoltWay' on quotations and e-mails must be treated as this supplier [^r1][^r2]. According to [[pol-sup-003|POL-SUP-003]], these variants for the entity in Eindhoven map directly to this active supplier record [^r1][^r2].

## Versions and conflicts
- Today's rule: Voltway Cells (Eindhoven) is active under code VC-EIN-0042, and previous code VC-EIN-0009 is blocked and marked '(old code, do not use)' [^r1][^r3].
- Older rule: In superseded POL-SUP-003 v2.2, the blocking and renaming of VC-EIN-0009 as '(old code, do not use)' and handling of name variations like 'Voltway Cells B.V.' or 'VoltWay' were described under earlier code replacement examples [^r4][^r5].
- Sources and dates: POL-SUP-003 v2.3 (2026-04-01) supersedes POL-SUP-003 v2.2 [^r1][^r4].
- Kind: superseded.
